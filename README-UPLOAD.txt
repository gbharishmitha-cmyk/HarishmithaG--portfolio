HARISHMITHA PORTFOLIO — WITH JAVA GITHUB LINK

Files included: index.html, style.css, script.js, and assets/. Keep the folder structure unchanged.

RUN ON YOUR COMPUTER
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the portfolio in your browser.

PUBLISH WITH GITHUB PAGES
1. Upload all files and the assets folder to the root of your portfolio repository.
2. In GitHub, open Settings > Pages.
3. Select Deploy from a branch, branch main, folder /(root), then Save.
4. Wait a few minutes and open the Pages website link.

The Projects section now has a button that opens: https://github.com/gbharishmitha-cmyk/java-programming
